# Decentraland Creator Hub (releases only)

**The source code has moved to [decentraland/dcl-one](https://github.com/decentraland/dcl-one/tree/main/apps/creator-hub), under `apps/creator-hub`.** Development, issues and pull requests all happen there now.

This repository stays for one reason: it hosts the Creator Hub **installer releases**. Installed apps check its [Releases](https://github.com/decentraland/creator-hub/releases) for updates (the `latest.yml` and `latest-mac.yml` feeds), so it can't be archived or deleted.

- **Releases** are built and published here by dcl-one's CI. A new version first appears as a pre-release and becomes the Latest release once someone promotes it in dcl-one.
- **`@dcl/inspector` and `@dcl/asset-packs`** are published to npm from dcl-one.
- **The code in this repository** is frozen at the move and kept for history and old links. `main` is locked, and this repository's CI is disabled.
